Сюда кладём видео для проектов.

Видео для карты «Ледяной Пророк» (ЛП): положи файл сюда под именем  lp.mp4
(формат MP4 / H.264 + AAC — он играет на всех телефонах и браузерах).

Другое имя файла или YouTube — меняется в public/js/projects.js:
  video: { src: 'videos/lp.mp4', youtube: '', poster: 'img/map1_cover.webp' }
Для YouTube впиши только id ролика, например  youtube: 'dQw4w9WgXcQ'
